评估指标快速参考（简要）

The travel evaluator emits the following normalised scores (0-1 range):

- overall_score — blended aggregate of the component metrics listed below.
- task_success_rate — proportion of tasks whose user-side milestones were all satisfied.
- task_complete_rate — average completion ratio across all user milestones.
- execution_efficiency — milestone completion divided by the number of distinct agents engaged.

Default metric weights used for the overall score:

- task_success_rate: 33%
- task_complete_rate: 33%
- execution_efficiency: 34%

All per-task values feed directly into the summary cards and downstream JSON/HTML reports.
